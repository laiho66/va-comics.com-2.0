VANGUARD CHRONICLES // COVERS
=============================
Put the web version of each book cover here:

    book1.webp   (Book 1)
    book2.webp   (Book 2, when it exists)
    ...

Specs:
  - ratio 5:7 (same as the print file), about 800 x 1120 px
  - WebP format, under 150 KB
  - the file name must be EXACTLY like above (lower case, no spaces)

Do NOT upload the 3500 x 5000 print files here (they are too heavy for the site).
