Connect in Settings first.

The token stays only in this browser (local storage). It is never in the site's files and never sent anywhere except to GitHub.
  1. GitHub → your picture (top right) → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: foundry. Expiration: 90 days (you will make a new one then).
  3. Repository access → Only select repositories → va-comics.com-2.0 (the one with -2.0).
  4. Permissions → Repository permissions → Contents → Read and write. Nothing else.
  5. Generate, copy the token once and paste it above.
