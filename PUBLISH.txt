C. PUBLICAREA, PAS CU PAS
-------------------------
1. GitHub > repo > butonul cu branch-uri > scrii  v3.2  > Create branch from main.
2. Pe branch-ul v3.2: Add file > Upload files. Tragi conținutul folderului (fișierele și folderele, NU zip-ul).
   GitHub îți arată ce se înlocuiește. Commit direct pe branch-ul v3.2, nu pe main.
   (Variantă mai comodă pentru foldere mari: GitHub Desktop. O parcurgem împreună dacă vrei.)
3. Aștepți bifa verde, deschizi linkul de preview (Cloudflare) și parcurgi lista de la D.
4. Dacă totul e bine: Compare & pull request > Create > Merge. Site-ul live se actualizează în 1-2 minute.
5. Dacă ceva nu merge: nu faci Merge. Corectezi pe branch, sau ștergi branch-ul.
6. După Merge, dacă ai o problemă gravă: Revert pe PR, sau rollback în Cloudflare (Deployments).
